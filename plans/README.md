## Findings considered and rejected (do not re-audit)

Owner's standing decisions and by-design behaviour:

- Legacy protocol is unauthenticated on the LAN - by design (ADR-002, ADR-008).
- Extensions run trusted - by design (ADR-012). `.asar` packages are the plugin API (ADR-014).
- No tablet dimming / brightness control - owner rejected.
- `crates/aidev` is frozen - not audited, not to be refactored.
- 10 Hz flusher and 64 MiB Boa stacks - kept deliberately.
- Double keepalive, BootReceiver limited to API 29+, non-atomic `requestCounter`, clock tile tick - reviewed earlier and rejected as non-issues.

From this audit:

- `@vue/test-utils` moderate advisories - the only "fix" is a downgrade; left to Dependabot.
- Auto-uninstalling a differently-signed tablet build - destroys pairing; kept a human decision (plan 032 only explains).
- Dismissing the desktop pairing dialog when the tablet cancels - needs a cancellable operator gate; noted as future work in plan 034.
